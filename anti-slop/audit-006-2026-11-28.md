## Numbered Findings (Choose Which Numbers to Fix)

### 1. [Medium | Editorial Consistency] Section watermark numbers skip `02` if `JourneySection` is hidden in Admin
- **Where:** `src/pages/HomePage.jsx`, `src/components/sections/ExperienceSection.jsx`, `ProjectsSection.jsx`, `ContactSection.jsx`
- **Issue:** `ExperienceSection` (`"03"`), `ProjectsSection` (`"04"`), and `ContactSection` (`"05"`) hardcode their watermark numbers. If the admin empties the Career Timeline so `JourneySection` (`"02"`) hides, the background editorial numbering jumps directly from `01` to `03`.
- **Suggested Fix:** Pass an optional `sectionIndex` prop (defaulting to `'03'`, `'04'`, `'05'`) from `HomePage.jsx` derived from `hasJourney` so the visible editorial numbering is always sequential (`01`..`04` when Journey is hidden, `01`..`05` when visible).

### 2. [Low | Mobile Performance] Skip `useSpring` smoothing in `ParallaxLayer` when `effectiveFactor === 0`
- **Where:** `src/components/common/ParallaxLayer.jsx` (lines 52-60)
- **Issue:** On mobile/tablet (`<= 1023px`), sections using `mobileFactor={0}` (About bio, Experience columns, Projects header, Contact form) have `yRange = [0, 0]`, yet `smoothProgress` is still passed into `useTransform` on scroll.
- **Suggested Fix:** Gate `progress` with `smooth && !prefersReducedMotion && effectiveFactor !== 0 ? smoothProgress : scrollYProgress` so stationary mobile layers bypass spring interpolation cleanly.

### 3. [Low | Reduced Motion Live Parity] `SeasonalCanvas` only checks `prefers-reduced-motion` on mount
- **Where:** `src/features/season/SeasonalCanvas.jsx` (lines 162-167)
- **Issue:** `ParallaxLayer` reacts immediately if a user toggles OS Reduced Motion while the page is open, whereas `SeasonalCanvas` reads `matchMedia('(prefers-reduced-motion: reduce)').matches` only on mount.
- **Suggested Fix:** Subscribe to the `prefers-reduced-motion` `MediaQueryList` `change` event inside `SeasonalCanvas` so toggling Reduced Motion immediately pauses/clears the canvas loop without requiring a reload.
