## Numbered Findings (Choose Which Numbers to Fix)

### 1. [Important | Test Fidelity] Component unit tests render `m.*` without `<LazyMotion features={domMax}>`
- **Where:** `test/components/sections/ProjectsSection.test.jsx`, `test/components/sections/ProjectModal.test.jsx`, `test/components/sections/ExperienceSection.test.jsx`, `test/components/layout/Layout.test.jsx`
- **Issue:** Only `test/App.test.jsx` wraps renders in `<MotionConfig reducedMotion="user"><LazyMotion features={domMax}>`. Without `LazyMotion`, `m.*` renders as static elements and never runs real `AnimatePresence` / `layout` lifecycles during component tests.
- **Suggested Fix:** Wrap component test harnesses in `<MotionConfig reducedMotion="always"><LazyMotion features={domMax} strict>` (using `reducedMotion="always"` in JSDOM so animations settle deterministically while still verifying `strict` compliance and `AnimatePresence` lifecycles).

### 2. [Medium | Motion Polish] `ProjectsSection` unmounts `<AnimatePresence>` when search filters down to 0 results
- **Where:** `src/components/sections/ProjectsSection.jsx` (lines 250-290)
- **Issue:** Switching between `#projects-empty-state` and `#projects-grid` unmounts `<AnimatePresence mode="popLayout">`, causing remaining cards to snap out abruptly instead of transitioning smoothly into the empty state.
- **Suggested Fix:** Keep the empty-state transition smooth by wrapping the empty state / grid switch cleanly with subtle `opacity` fade (`m.div` with `EDITORIAL_EASE`) while preserving `id="projects-empty-state"` and `#projects-grid` selectors.

### 3. [Medium | React Hygiene] Redundant nested `<TooltipProvider>` in `HeroSection.jsx` and `FloatingActions.jsx`
- **Where:** `src/components/sections/HeroSection.jsx` (line 103), `src/components/layout/FloatingActions.jsx` (line 24)
- **Issue:** `src/App.jsx` already mounts a root `<TooltipProvider delayDuration={200}>`, so nested `<TooltipProvider>` wrappers in `HeroSection` and `FloatingActions` duplicate provider state.
- **Suggested Fix:** Remove duplicate `<TooltipProvider>` wrappers from `HeroSection.jsx` and `FloatingActions.jsx` (wrapping standalone unit tests in `<TooltipProvider>` where needed).

### 4. [Low | Performance / LCP] Add `<link rel="preload">` for WebP Hero portrait in `index.html`
- **Where:** `index.html`
- **Issue:** Even though `#hero-img` has `fetchPriority="high"` and is now only `74.6 KB` as WebP, the browser discovers it only after JS renders `HeroSection`.
- **Suggested Fix:** Add `<link rel="preload" as="image" type="image/webp" href="/assets/images/arko-pic.webp" fetchpriority="high" />` in `index.html` `<head>` so the Hero portrait starts downloading immediately alongside JS.

### 5. [Low | Dead Code / Dependency Bloat] Unused `cmdk` dependency and `src/components/ui/command.jsx`
- **Where:** `package.json` (`cmdk`), `src/components/ui/command.jsx`
- **Issue:** `CommandPalette.jsx` uses a custom Radix `Dialog` implementation, leaving `src/components/ui/command.jsx` and the `cmdk` npm package completely unused across `src/` and `test/`.
- **Suggested Fix:** Delete unused `src/components/ui/command.jsx` and uninstall `cmdk` from `package.json`.
