## Numbered Findings (Choose Which Numbers to Fix)

### 1. [Medium | Copywriting / Anti-Slop] Generic AI-cliché placeholder `"Alex Rivera"` in `ContactSection.jsx`
- **Where:** `src/components/sections/ContactSection.jsx` (lines 367 & 386)
- **Issue:** Input placeholders currently use `"Alex Rivera"` and `"alex@company.com"`, a recognizable AI-generated placeholder persona.
- **Suggested Fix:** Replace with crisp, neutral functional placeholders (`"Your full name"` and `"you@domain.com"`).

### 2. [Medium | Contrast / WCAG AA] Light-mode `--destructive-text` (`#dc2626`) drops to `4.13:1` on `bg-destructive/10` tint
- **Where:** `src/styles/index.css` (line 26), `src/components/sections/ContactSection.jsx` (line 456), `src/pages/admin/tabs/AdminMessagesTab.jsx` (line 299)
- **Issue:** On pure white `#ffffff`, `#dc2626` passes AA (`4.83:1`), but on `bg-destructive/10` (`#fce9e9`, used in error banners and destructive icon button hover states) contrast drops to `4.13:1`, below the `4.5:1` WCAG AA text threshold.
- **Suggested Fix:** Darken light-mode `--destructive-text` to `#b91c1c` (`6.47:1` on `#ffffff` and `5.57:1` on `#fce9e9`), keeping dark-mode `--destructive-text: #f87171` (`6.37:1` on card, `6.00:1` on tint).

### 3. [Low | React Lifecycle Hygiene] Uncleaned `setTimeout(..., 0)` in `Send Another Message` reset handler
- **Where:** `src/components/sections/ContactSection.jsx` (line 298)
- **Issue:** Clicking `Send Another Message` schedules `setTimeout(() => nameInputRef.current?.focus(), 0)` without cleanup if the component unmounts before the callback runs.
- **Suggested Fix:** Use a `shouldFocusNameRef` handled inside a `useEffect` triggered when `submittedInfo` transitions back to `null`, cleanly eliminating the unmanaged timeout.

### 4. [Low | Admin Usability] Add quick `Copy Email` action alongside `Reply via Email` in `AdminMessagesTab`
- **Where:** `src/pages/admin/tabs/AdminMessagesTab.jsx` (lines 396-402)
- **Issue:** Admins using webmail (Gmail/Outlook Web) instead of a desktop `mailto:` handler have to manually highlight and copy sender email addresses from inbox cards.
- **Suggested Fix:** Add an accessible `Copy email address` button (`size-11 sm:size-7`) next to the sender email in `AdminMessagesTab` with `Sonner` toast feedback.
